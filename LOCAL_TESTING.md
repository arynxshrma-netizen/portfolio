# 🚀 Local Testing Guide

Ab tu locally run karke dekh sakta hai sab kaise dikhta hai!

---

## Step 1: Clone Repository

```bash
git clone https://github.com/arynxshrma-netizen/portfolio.git
cd portfolio
```

## Step 2: Install Dependencies

```bash
npm install
```

(Wait 2-3 minutes...)

## Step 3: Run Locally

```bash
npm run dev
```

## Step 4: Open Browser

Go to: **`http://localhost:3000`**

## 💡 What to Customize Next:

1. **Showreel Video**
   - Upload your showreel MP4/WebM
   - Update video player link

2. **About Text**
   - Replace placeholder with your actual bio

3. **Projects**
   - Edit `src/lib/data.js`
   - Add 4-5 of your best projects

4. **Before/After Images**
   - Add actual before/after screenshots

5. **Testimonials**
   - Replace with real client quotes
