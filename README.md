# Aryan Sharma - Video Editor & Motion Graphics Portfolio

Premium portfolio website showcasing 5+ years of professional video editing and motion graphics work.

**Live:** [Coming Soon on Vercel]  
**Tech Stack:** Next.js 14, React, TailwindCSS

## 🚀 Quick Start

```bash
npm install
npm run dev
# Open http://localhost:3000
```
